# Pax Omni Bot for macOS

Download the latest version:
**[Pax-Omni-Bot.dmg](https://github.com/pax-beehive/paxchat-desktop/releases/latest/download/Pax-Omni-Bot.dmg)**

It runs on macOS 14.4 or later, on Apple silicon and Intel Macs. Open the
disk image and drag Pax Omni Bot to Applications. The app is signed and
notarized by Apple.

Pax Omni Bot uses the same account and conversation as
[paxomnibot.com](https://paxomnibot.com). Every version is listed under
[Releases](https://github.com/pax-beehive/paxchat-desktop/releases).
